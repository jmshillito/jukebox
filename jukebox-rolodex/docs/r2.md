# Cloudflare R2 Setup

R2 stores MP3 files privately. Playback should only happen via signed URLs.

## Bucket
- Create a private bucket in R2.
- Use the S3-compatible endpoint for API access.

## Object keys
Use this key layout for uploads:

```
users/<clerkUserId>/songs/<songId>.mp3
```

## Environment variables
Set these in Vercel and local `.env`:

```
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET=
R2_ENDPOINT=
```

Notes:
- `R2_ENDPOINT` is your S3-compatible endpoint (e.g. `https://<account>.r2.cloudflarestorage.com`).
- Keep the bucket private; do not enable public access.
